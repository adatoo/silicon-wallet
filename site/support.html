I forgot my master password

It can't be recovered or reset. It's the only key to your vault, and nobody, including us, has a copy. Write it down somewhere safe, away from your devices.

Sync isn't working

Check that the device is signed in to iCloud and that iCloud Drive is on. The sync icon in the toolbar shows the status; tap it to sync now. Your vault stays on the device while sync waits.

Moving from Acrylic Wallet

Choose File ▸ Import from Acrylic Wallet (or Settings ▸ Import). On a Mac, Wallet keeps its vault at ~/Library/Containers/com.acrylic.WalletMac/Data/Library/Application Support/Wallet/Database.wallet: in the file picker press ⇧⌘G and paste that path. Enter your old Wallet password, check the preview, and import. Silicon Wallet doesn't change the old file.

Once you've checked your entries, delete the old file, any Dropbox copy and any "Wallet Database" exports. Wallet uses your password directly as its encryption key, with no slow hashing step, so anyone with a copy of an old file can try passwords against it very quickly.

Silicon Wallet reads files from Wallet 3 for Mac. If it says a file uses a format it can't read yet, please open an issue on GitHub (never attach the file).
