## How to add or change an ADR

- **New:** copy the shape of 0001, use the next number, set the status to Accepted, and add it
  to this index in the same PR. Numbers are never reused.
- **Changed decision:** edit the ADR in place, and update its status and date. Git history
  records what it used to say.
- **Dropped decision:** set its status to `Withdrawn` with a line on why, and update this index.
- Changing a decision needs the owner's explicit instruction.
