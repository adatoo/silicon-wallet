# Security

Silicon Wallet stores secrets, so security reports get priority.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub's
"Report a vulnerability" button on this repository's Security tab. Include the steps to
reproduce it and the version affected.

You'll get an acknowledgement within a few days. Please give us a reasonable time to ship a fix
before you disclose it.

## Design

How the vault is encrypted, what is and isn't stored in plaintext, and how sync works are
